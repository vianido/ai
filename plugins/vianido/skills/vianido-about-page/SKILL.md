# Editing the About page

Block writes are drafts; nothing reaches the public page until it is published. For the words in each block, follow `vianido-writing`.

## Start

`list_organization_about_blocks`, then tell the user what the page shows now: the live blocks in order, and any drafts or hidden blocks. A draft may be someone else's unfinished work; ask before changing or publishing it.

## Plan the page

For a new or mostly empty page, propose an outline before drafting any block: a heading and a short text for each part of the story (who they serve, programs, history, results), with images, a quote, stats or people where the sources support them. One idea per block. Draft it once the user agrees.

## Blocks

- **Images**: reuse what `list_organization_media` already holds before uploading. Upload only photos the user provides or confirms the organization owns. Alt text says what the picture shows, for someone who can't see it.
- **Quote**: a real person's words, attributed as they agreed to be named, with their consent.
- **Stats**: shows metrics the organization already has; add them first with the metric tools.
- **People**: only people the user names, with the role they hold, and photos only with their consent.
- **Video**: link a YouTube or Vimeo video. An uploaded video is added on the Vianido website.

## Publish

Show each draft as it will read, then publish when the user asks. Publish a single block when only that one is ready; publishing the page publishes every draft on it, so check there are no others first. Re-read the page after publishing and report what is live.

## Arrange

Hiding, moving and deleting take effect at once. Prefer hiding a block the user may want back; delete only when they ask.
